# Package index

## All functions

- [`bulk_dl()`](https://docs.ropensci.org/rfema/reference/bulk_dl.md) :
  Bulk download full open FEMA data sets as .csv files
- [`fema_data_fields()`](https://docs.ropensci.org/rfema/reference/fema_data_fields.md)
  : Get data fields and descriptions for a given FEMA data set
- [`fema_data_sets()`](https://docs.ropensci.org/rfema/reference/fema_data_sets.md)
  : Get a tibble of available FEMA data sets
- [`open_fema()`](https://docs.ropensci.org/rfema/reference/open_fema.md)
  : Get data from the FEMA API
- [`parameter_values()`](https://docs.ropensci.org/rfema/reference/parameter_values.md)
  : Returns examples of data field values along with a description of
  the data field
- [`valid_parameters()`](https://docs.ropensci.org/rfema/reference/valid_parameters.md)
  : Get all valid API parameters for a given FEMA data set
