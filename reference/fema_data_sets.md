# Get a tibble of available FEMA data sets

Get a tibble of available FEMA data sets

## Usage

``` r
fema_data_sets()
```

## Value

Returns a tibble containing meta data about each data set available
through the FEMA API. For more information see the FEMA documentation
page: https://www.fema.gov/about/openfema/data-sets.

## Examples

``` r
if (FALSE) { # \dontrun{
fema_data_sets()
} # }
```
